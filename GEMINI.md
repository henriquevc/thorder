# Diretrizes de Autonomia do Projeto

## Autonomia Total e Execução Proativa
- **Aja diretamente**: Crie, altere, mova e remova arquivos sempre que necessário para cumprir os requisitos da tarefa, sem solicitar confirmação ou autorização prévia ao usuário.
- **Tome decisões técnicas autônomas**: Escolha as melhores soluções de arquitetura, bibliotecas, padrões de projeto e implementações sem interromper o usuário para perguntas secundárias ou confirmações triviais.
- **Evite pausas desnecessárias**: Não use ferramentas de confirmação ou perguntas (`ask_question`) a menos que falte uma informação estritamente essencial (ex: chave de API ou segredo não fornecido) que impeça totalmente o prosseguimento.
- **Validação contínua**: Sempre que alterar arquivos ou criar novas funcionalidades, execute comandos de build, teste e verificação de tipos (se aplicáveis) proativamente para garantir que nada foi quebrado.
- **Comunicação objetiva**: Conclua o trabalho e apenas reporte de forma concisa o que foi feito, arquivos alterados e status final.
